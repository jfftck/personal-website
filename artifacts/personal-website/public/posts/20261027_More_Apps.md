# More Apps

I've been busy adding games and additional desktop apps. It's been a lot of fun developing a more complete modern desktop as my personal page. This started as an experiment to see how complex of an app I could build with AI, so far I haven't found a task that I needed to build myself and have only directed the AI to use the same design patterns and styling that I would have done myself. There are many times I would need to correct it, but after the additional requirements it would end up with something that I would only have to make small refinements to and then call it a completed feature.

So, please check out the desktop that I've built and how I have worked to maintain a consistent style.
