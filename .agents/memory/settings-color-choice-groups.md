---
name: Settings color choice groups
description: Accessible naming for paired color selectors that reuse visible color names.
---

When a settings page has multiple color selectors with repeated visible names, include the selector role in each accessible name (for example, distinguish dark tint from light tint) and scope automation to the named group.

**Why:** Paired tint controls introduced identical color labels, which made browser-test locators ambiguous and reduced clarity when addressing a choice by name.

**How to apply:** Use contextual names and group labels for any paired theme, foreground, or background color palettes.
