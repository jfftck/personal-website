---
name: Toolbar button style
description: User direction for consistent toolbar action styling across the desktop.
---

**Rule:** Keep toolbar action buttons and menu triggers borderless like File Manager, while preserving keyboard focus rings, pressed/selected feedback, and toolbar separators.

**Why:** The user asked for consistent toolbar styling across every app and prefers File Manager's borderless action buttons.

**How to apply:** Use the quiet toolbar-button treatment for app, game, calendar, calculator, and note toolbars. Do not remove borders from unrelated form fields or popover contents.
